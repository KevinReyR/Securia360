# Securia Copilot

Copilot solo recupera información ya autorizada al actor por tenant y registra conversación, fuente, versión, contexto y propuesta. El contenido documental se trata como datos no confiables: no habilita herramientas ni instrucciones.

No existe un ejecutor autónomo. Clasificación, aprobaciones y decisiones legales o médicas se guardan como propuestas pendientes de confirmación humana con auditoría.
