# Facturación y administración SaaS

Planes, suscripciones, límites y flags son estado comercial; no se usan para autorizar filas ni reemplazan RLS. Una suspensión cambia disponibilidad comercial, nunca elimina datos del tenant.

No hay proveedor conectado. Los webhooks se almacenan con referencia única, hash y estado de firma para un procesador futuro autorizado. Los administradores de Reinova Labs viven en un esquema privado; toda sesión de soporte queda auditada y separada de las membresías del tenant.
