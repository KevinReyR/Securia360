# Comités, auditorías e indicadores

Los comités usan tipos configurables; COPASST y Convivencia son semillas, no reglas rígidas. Cada período conserva sus miembros, reuniones, agenda, asistencia, acta y compromisos enlazables a tareas. Un acta aprobada es inmutable.

Las auditorías separan programa, ejecución, equipo, lista, evidencia, hallazgo, informe y acción. Si una ejecución requiere independencia, cualquier integrante del equipo auditor queda impedido de aprobar su propio informe.

Los indicadores separan catálogo, versión y resultados históricos. Las ejecuciones usan una clave de idempotencia y guardan la versión exacta, período, dimensiones y explicación. El dashboard es una vista de estado actual con security invoker; no sustituye snapshots normativos.
