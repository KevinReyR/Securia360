# Incidentes y datos sensibles

El caso operativo, la investigación, acciones y comunicaciones se separan de `incident_sensitive_details`. Esta última solo está disponible para el permiso específico `incidents.sensitive`. No contiene diagnósticos ni conclusiones médicas o jurídicas.

Las evidencias usan documentos privados existentes y se descargan mediante URLs firmadas de corta duración. Los formatos de exportación son plantillas versionadas y preparadas; no sustituyen reportes oficiales ni automatizan decisiones profesionales.

La aplicación no permite nuevas notas sanitarias libres. El campo heredado `health_information_note` se conserva solo para lectura médica restringida y no se muestra en interfaz. Salud ocupacional administra conceptos funcionales, restricciones mínimas, programas y vencimientos; no almacena historias clínicas ni diagnósticos. Toda decisión que afecte a una persona inicia pendiente y debe ser confirmada por otro usuario autorizado.
