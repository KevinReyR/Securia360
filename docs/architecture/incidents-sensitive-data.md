# Incidentes y datos sensibles

El caso operativo, la investigación, acciones y comunicaciones se separan de `incident_sensitive_details`. Esta última solo está disponible para el permiso específico `incidents.sensitive`. No contiene diagnósticos ni conclusiones médicas o jurídicas.

Las evidencias usan documentos privados existentes. Los formatos de exportación son plantillas versionadas y preparadas; no sustituyen reportes oficiales ni automatizan decisiones profesionales.
